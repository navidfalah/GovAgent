## بررسی اجمالی

سیستم **GovAgents** پیشنهادات و معماری‌های فنی سیستم‌های هوش مصنوعی را در برابر مجموعه‌ای پیچیده از سیاست‌های جهانی (مانند قانون هوش مصنوعی اتحادیه اروپا، GDPR، چارچوب NIST RMF و اصول OECD) ارزیابی می‌کند تا تصمیمات حاکمیتی مبتنی بر شواهد ارائه دهد.

به جای اتکا به یک مدل زبان بزرگ (LLM) واحد برای انجام تمام استدلال‌ها، GovAgents از یک **معماری تخصصی چندعامله (Multi-Agent)** استفاده می‌کند که در آن عامل‌ها (Agents) بر روی جنبه‌های متمایزی از حاکمیت (مانند ریسک، اخلاقیات، معماری فنی، و انطباق با خط‌مشی‌ها) تمرکز دارند. اخیراً این سیستم به پشتیبانی از **زنجیره تفکر (Chain of Thought)** مجهز شده است تا دقت استدلال‌ها افزایش یافته و خطاهای توهم (Hallucination) مدل کاهش یابد.

## ویژگی‌های کلیدی

- 🤖 **۶ عامل تخصصی**: عامل‌های اختصاصی برای بازیابی خط‌مشی (Policy Retrieval)، ارزیابی ریسک، بررسی فنی، انطباق، اخلاقیات و ترکیب نهایی تصمیمات حاکمیتی.
- 🧠 **استدلال پیشرفته (Chain of Thought)**: مدل‌ها ملزم هستند قبل از تولید خروجی JSON، به صورت مرحله به مرحله منطق خود را در بلوک‌های `<thought>` شرح دهند.
- 🧩 **معماری پلاگین پیشرفته**: عامل‌ها و قابلیت‌ها (ابزارها) به صورت پویا از طریق سیستم `@registry` بارگذاری می‌شوند که توسعه‌پذیری سیستم را بسیار بالا می‌برد.
- 📡 **انتشار/اشتراک رویدادمحور (Pub/Sub)**: ارتباط بین عامل‌ها توسط یک گذرگاه پیام (Message Bus) ناهمگام مدیریت می‌شود که از رویدادهای Server-Sent Events (SSE) به صورت بلادرنگ پشتیبانی می‌کند.
- ⚖️ **مناظره خودکار عامل‌ها**: اختلاف نظر بین عامل‌ها (مثلاً اگر عامل فنی با عامل ریسک در مورد شدت یک تهدید اختلاف نظر داشته باشد) تشخیص داده شده و از طریق یک پروتکل مناظره LLM حل می‌شود.
- 📚 **پیکره خط‌مشی RAG**: ادغام داخلی و جستجوی معنایی (ChromaDB) بر روی یک پیکره خط‌مشی پیچیده مبتنی بر YAML.
- 🎨 **رابط کاربری شیشه‌ای (Glassmorphism) فوق‌پیشرفته**: یک وب‌اپلیکیشن تک‌صفحه‌ای (SPA) با حالت تاریک (Dark Mode) چشم‌نواز با انیمیشن‌های روان و پس‌زمینه‌های پویای سه‌بعدی برای مصورسازی بلادرنگ خط لوله عامل‌ها.

## 🏗️ معماری

سیستم GovAgents از یک معماری پویا و جداسازی شده استفاده می‌کند که به شدت به تزریق وابستگی (Dependency Injection) و ریجستری پلاگین (Plugin Registry) متکی است.

```text
govagents/
├── core/           # ظرف DI، رجیستری پلاگین، مدل‌های Pydantic مشترک، کلاینت LLM پیشرفته
├── capabilities/   # ابزارهای قابل استفاده مجدد (مانند جستجوی برداری) که به عامل‌ها تزریق می‌شوند
├── agents/         # عامل‌های خودکار کشف‌شده (سیاست، ریسک، فنی، انطباق، و غیره)
├── orchestration/  # هماهنگ‌کننده ناهمگام، پروتکل مناظره، گذرگاه پیام رویدادمحور
├── policies/       # تجزیه‌کننده پیکره YAML، ادغام با ChromaDB، بازیابی معنایی
├── api/            # مسیرهای FastAPI و جریان‌سازی SSE
└── frontend/       # رابط کاربری تحت وب با استایل Glassmorphism (Vanilla JS/CSS)
```

### خط لوله عامل‌ها (The Agent Pipeline)
۱. **تحلیل موازی**: عامل **سیاست (Policy)** قوانین را بازیابی می‌کند، عامل **ریسک** بردارهای تهدید را محاسبه می‌کند و عامل **فنی** معماری را بررسی می‌کند.
۲. **ارزیابی ترتیبی**: عامل **انطباق (Compliance)** و عامل **اخلاقیات (Ethics)** یافته‌های فاز ۱ را ارزیابی می‌کنند.
۳. **مناظره (Debate)**: اگر هماهنگ‌کننده (Orchestrator) متوجه تضاد در استدلال عامل‌ها شود، پروتکل مناظره را برای حل آن فعال می‌کند.
۴. **ترکیب و نتیجه‌گیری (Synthesis)**: عامل **حاکمیت (Governance)** تمام خروجی‌ها را بررسی کرده و تصمیم نهایی را به صورت `تایید شده`، `تایید مشروط`، `رد شده` یا `ممتنع` صادر می‌کند.

## 🚀 شروع به کار

### پیش‌نیازها
- Python 3.10+
- کلید API برای Google Gemini (مورد استفاده از طریق LiteLLM)

### نصب

۱. **مخزن را کلون کرده و یک محیط مجازی راه‌اندازی کنید:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

۲. **نصب وابستگی‌ها:**
```bash
pip install -e ".[dev]"
```

۳. **تنظیم متغیرهای محیطی:**
```bash
cp .env.example .env
# فایل .env را باز کنید و کلید GEMINI_API_KEY خود را اضافه کنید
```

### راه‌اندازی سریع (Quickstart)

**۱. پردازش و ادغام پیکره خط‌مشی‌ها (Ingest)**  
این دستور، خط‌مشی‌های YAML (مانند EU AI Act و GDPR) را تجزیه کرده و تعبیه‌های (Embeddings) محلی را در ChromaDB ایجاد می‌کند.
```bash
python3 scripts/ingest_policies.py
```

**۲. اجرای سرور FastAPI**
```bash
uvicorn govagents.api.main:app --host 0.0.0.0 --port 8000 --reload
```

**۳. اجرای یک ارزیابی**  
مرورگر خود را باز کرده و به آدرس `http://localhost:8000` بروید. شما می‌توانید یک پیشنهاد نمونه (مثلاً "نظارت بر کارمندان") را انتخاب کنید و به صورت بلادرنگ مشاهده کنید که چگونه خط لوله چندعامله استدلال خود را استریم می‌کند.

## 🛠️ توسعه سیستم (Extending the System)

سیستم GovAgents طوری طراحی شده است که به راحتی قابل توسعه باشد.

### افزودن یک عامل جدید
به لطف الگوی Plugin Registry، شما می‌توانید به سادگی با ارث‌بری از `BaseAgent` و استفاده از دکوراتور، یک عامل جدید اضافه کنید.

```python
from govagents.agents.base import BaseAgent
from govagents.core.registry import registry
from govagents.core.models import AgentRole

@registry.register_agent("SecurityAgent")
class SecurityAgent(BaseAgent):
    role = AgentRole.TECHNICAL
    description = "صرفاً بر روی مدل‌سازی تهدیدات امنیت سایبری تمرکز دارد."
    
    async def run(self, context):
        # پیاده‌سازی منطق عامل در اینجا
        pass
```

### افزودن یک قابلیت (Tool) جدید
شما می‌توانید منطق‌های پیچیده را استخراج کرده و به عنوان ابزار (Capability) به هر عاملی تزریق کنید.

```python
from govagents.capabilities.base import Capability
from govagents.core.registry import registry

@registry.register_capability("WebSearch")
```
